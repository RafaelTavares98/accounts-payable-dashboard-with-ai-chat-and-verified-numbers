# Upwork portfolio item

**Title:** Accounts Payable Dashboard You Can Talk To, AI Chat with Verified Numbers

**Role:** Data analyst and Python developer

**Skills:** Python, FastAPI, Data Analysis, Data Visualization, LLM, Docker

**Media:** `demo.gif`

**Description:**

A live accounts-payable dashboard with a chat beside it. Ask "what is
overdue?" and the panels that answer open on screen.

The AI never produces a number. It picks which panels to show. Python
computes every figure from the invoice data. Then the AI writes one
sentence, and code checks every number in it before it is shown.

- 90 invoices read from PDFs, 1.1M owed, 10 suppliers
- Overdue ageing, weekly due dates, top suppliers and items
- Every row opens the original invoice PDF
- Five one-click questions that work with no AI at all
- Answers in about 6.5 seconds
- 306 automated tests, Docker deploy

Built for finance teams that need answers they can trust and trace
back to the source document.
