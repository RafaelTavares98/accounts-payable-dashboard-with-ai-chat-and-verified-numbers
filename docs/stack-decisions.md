# The stack

Docker, the DeepSeek V4 API, and what was decided on the way here.

## Decided

- **Python is the base, Docker runs it.** A JavaScript page is allowed
  for the lines and the glass look. The Python side owns the data and
  the numbers.
- **The subject is accounts payable.** The data is the CSV the invoice
  pipeline writes. An invoice Moty receives is an account payable.
- **The front end is one page served by FastAPI.** The server sends
  data, the browser draws. `src/web.py` holds both.
- **The chat lives inside the page**, as the reference does.
- **The refusal texts** are written, in `src/answering.py` and
  `src/routing.py`.

Nothing is left open in the stack itself. Publication is Rafael's call.

## Docker

One container runs the whole app: the page, the data, and the call to
the model. DeepSeek lives on its own servers, so nothing extra runs
inside the container for it.

- `docker compose up -d --build` is the whole install.
- The data sits in `data/`, generated by the invoice pipeline.
- The key is never in the image. It is read from the environment or
  from the Windows keyring, the same way the invoice pipeline does it.
- The demo date is pinned in `docker-compose.yml` so the demo never
  ages.
- The image installs from `requirements.txt`. Tests live in
  `requirements-dev.txt` and never enter the image.

## The model

### Facts read from the official docs on 2026-10-10

- The API is OpenAI-compatible. Base URL `https://api.deepseek.com`.
- Two models: `deepseek-flash` and `deepseek-v4-pro`.
- JSON output exists. It needs `response_format` of type
  `json_object` and the word "json" in the prompt.
- Tool calls exist, with a `strict` mode behind a beta base URL.
- Context length is one million tokens.

### Which one this project uses

`deepseek-v4-pro`, the model Rafael named. `deepseek-flash` stays as
the cheap option for tests.

### What each answer costs

Prices per one million tokens, read the same day.

| Model | Input, off-peak | Output, off-peak |
|---|---|---|
| deepseek-flash | US$ 0.15 | US$ 0.60 |
| deepseek-v4-pro | US$ 0.66 | US$ 1.98 |

Peak hours are 01:00 to 04:00 and 06:00 to 10:00 UTC, weekdays. Peak
doubles these numbers. One question costs a few thousand tokens, so
each question costs a fraction of a cent.

### How the model is used

- One call per question. A test counts the calls.
- The JSON names the panels. Code computes every number.
- The sentence is written after the numbers exist, so the model never
  guesses a figure.
- A sentence with a number nobody computed is replaced by code.
