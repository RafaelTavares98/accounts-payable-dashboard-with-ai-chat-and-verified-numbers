Comportamento do dashboard com chat

Fonte: o vídeo MUST REPLICATE NOW.mp4, o texto do criador em MUST REPLICATE.txt e a descrição falada do Rafael. Cada passo mostra frames do próprio vídeo, com o segundo de cada um. Escrito em 2026-10-10.

Passo a passo, com os frames do vídeo

Passo 1. O dashboard abre.

A visão base mostra os números de contas a pagar para os filtros atuais. São 15.000 linhas, de 2024 a 2027. Filtros de categoria, centro de custo, status, filial e período. Quatro visões em uma barra lateral.

Passo 2. O usuário clica no botão de chat.

Um painel de chat aparece ao lado do dashboard. O painel é uma coluna com histórico de mensagens.

Passo 3. O chat oferece respostas prontas.

Algumas perguntas já estão escritas, uma em cada botão. O usuário não digita. Ele clica em uma delas.

Passo 4. A resposta chega em uma frase.

A frase diz o número e o recorte de dados que usou. Exemplo do vídeo: "3.483 contas vencidas no filtro atual do painel, com atraso médio de 482 dias."

Passo 5. Linhas são desenhadas.

Linhas animadas saem da resposta que ele clicou e vão até os novos painéis. Cada linha liga a resposta a um painel.

Passo 6. Novos painéis abrem sobre o dashboard base.

Cada painel mostra a mesma análise por outra dimensão: por mês, por categoria, por fornecedor, por centro de custo, por forma de pagamento. Os painéis parecem folhas de vidro azul sobre o dashboard.

Passo 7. O ciclo repete.

Cada pergunta nova abre o tipo de painel que combina com ela. Uma pergunta sobre totais abre um conjunto. Uma pergunta sobre atraso abre outro. Um botão "Fechar painéis" fecha tudo.

A regra do projeto. Todo número vem do código, calculado direto sobre os dados filtrados. O modelo só lê a pergunta e escolhe quais painéis mostrar. Ele nunca inventa um número.

O que muda na nossa versão

  • O vídeo roda o modelo Phi-3.5 local no navegador, por WebGPU.
  • A nossa versão chama a API DeepSeek V4 e roda em Docker.
  • Todo o resto fica igual: o chat, as sugestões, as linhas, os painéis de vidro.
